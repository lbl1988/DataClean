# 快速开始

## 1. 获取API Key

注册账号后，在 [控制台](https://yourdomain.com/dashboard) 创建API Key。

你的Key格式为 `dk_live_xxxxx`，请妥善保存。

## 2. 第一次调用

### Python

```python
import requests

response = requests.post(
    "https://your-api-domain.com/v1/dedup",
    headers={"X-API-Key": "dk_live_your_key"},
    json={
        "records": [
            {"id": 1, "email": "ZhangSan@Gmail.com", "phone": "138-1234-5678"},
            {"id": 2, "email": "zhangsan@gmail.com", "phone": "13812345678"},
        ],
        "match_fields": ["email", "phone"],
        "match_mode": "fuzzy",
    },
)
print(response.json())
```

### curl

```bash
curl -X POST https://your-api-domain.com/v1/dedup \
  -H "X-API-Key: dk_live_your_key" \
  -H "Content-Type: application/json" \
  -d '{"records":[{"id":1,"email":"ZhangSan@Gmail.com","phone":"138-1234-5678"},{"id":2,"email":"zhangsan@gmail.com","phone":"13812345678"}],"match_fields":["email","phone"],"match_mode":"fuzzy"}'
```

### JavaScript

```javascript
const res = await fetch("https://your-api-domain.com/v1/dedup", {
  method: "POST",
  headers: { "X-API-Key": "dk_live_your_key", "Content-Type": "application/json" },
  body: JSON.stringify({
    records: [
      { id: 1, email: "ZhangSan@Gmail.com", phone: "138-1234-5678" },
      { id: 2, email: "zhangsan@gmail.com", phone: "13812345678" },
    ],
    match_fields: ["email", "phone"],
    match_mode: "fuzzy",
  }),
});
const data = await res.json();
console.log(data);
```
